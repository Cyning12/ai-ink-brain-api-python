ChatBI 系统 Text2SQL 模块详细流程规范（SDD 版）
1. 概述
本流程为系统处理用户自然语言查询的核心执行链路，采用双层 RAG + 有状态决策架构，支持知识问答与数据库查询（Text2SQL）两种业务模式，确保企业级数据安全、查询可控与结果准确。
2. 整体执行流程（正式 Spec 格式）
2.1 用户输入
输入：用户自然语言问题
输出：结构化意图与查询内容
2.2 意图识别 + 通用 RAG 检索
系统对用户 query 进行意图分类：
生成问题向量
检索通用知识库（文档、FAQ、业务规则）
判断是否需要查询结构化数据库
不需要 → 进入普通问答流程
需要 → 进入 Text2SQL 专用流程
2.3 Text2SQL 专用 RAG 检索
对用户问题进行向量检索，召回以下三类信息：
相关数据库表结构（DDL）
字段含义、业务口径、同义词说明
相似历史问题与示例 SQL（好题本）
2.4 LLM 生成 SQL
基于检索结果构建 Prompt，由大模型生成：
标准可执行 SQL
符合业务口径与表结构
无幻觉表 / 字段
2.5 SQL 安全校验与权限控制（企业强制）
执行前必须通过以下校验：
仅允许 SELECT 查询，禁止写操作
表白名单 / 字段黑名单校验
敏感字段过滤
行级权限自动拼接（用户部门 / 角色 TAG）
禁止无 WHERE 全表扫描
SQL 语法合法性检查
2.6 数据库查询执行
连接业务数据库执行 SQL
限制返回行数
超时控制、异常捕获
2.7 结果合理性校验
空结果判断
极值、异常数值识别
结果条数超限判断
执行失败自动反馈
2.8 自然语言总结
LLM 将结构化查询结果转换为自然语言回答，保证：
易读
准确
符合业务表达习惯
2.9 返回最终回答
将结果返回给用户。
