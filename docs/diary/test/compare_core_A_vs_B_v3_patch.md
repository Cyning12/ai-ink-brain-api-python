## 2. KPI 加权结论

### 2.1 P1 易交接（权重 40%）

**胜者**：**平局略偏 A（实现纵深）／平局略偏 B（索引与 SSE 配方）——按接手场景二选一**

| 维度 | A（补丁） | B（补丁） |
|------|-----------|-----------|
| **冷启动清单** | 10 步，紧凑；第 10 步固定写入 **manifest / manifest_check / contract_check**，闭环清晰。 | 13 步，强制 **图谱索引 → 代码核验**；含 drift、契约跨仓 CI，路径更长但更「制度化」。 |
| **锚点索引表** | **粒度极细**：大量 `文件 + 函数 + 行区间` + manifest/contract/**tools/workflow** 行号，便于直接跳转改代码。 | 全端点 + RPC/表/manifest；**补充** `_require_unified_auth`、`_require_code_api_auth` 等鉴权锚点；偏「索引总表」。 |
| **新人 FAQ** | 8 条，偏 **Legacy vs Unified、日期召回、keyword 兜底、ingest 幂等**。 | 10 条，额外覆盖 **manifest 与路由对齐、图谱 RPC 缩写、admin_secret 优先级、向量维度**。 |
| **改动配方卡** | 三卡齐全；卡 A 已含 **manifest + 门禁脚本 + CI**。 | 三卡 + **卡 D（SSE 契约）**，与 `_contract_manifest.json` / contract CI **显式对齐**，对改 Unified 流的接手方更省事。 |

**简述**：补丁后 **A 已补齐门禁叙事**，与 B 在「改 endpoint 必过 manifest」上对齐。**A** 更长于 **Legacy 链路细节与实现踩坑**（行号、降级、ingest 差异）。**B** 更长于 **图谱—manifest—契约—CI 一条龙索引**，并多出 **SSE 专用配方**。若接手人以「改后端实现」为主：**偏 A**；以「维护图谱与跨端契约」为主：**偏 B**。

### 2.2 P2 可靠性（权重 35%）

**胜者**：**B（略胜）**

| 指标 | A（补丁） | B（补丁） |
|------|-----------|-----------|
| **事实断言覆盖** | 约 **18** 条，覆盖流式契约、embedding 降级、RPC/SQL、manifest/contract 脚本与 CI。 | 约 **20** 条，含 **endpoint/anchor/table/RPC/env 数量级核验**声明。 |
| **防漂移元信息** | 强调 `tools/*.py`、workflows；不确定表中列未读 `vercel.json`、text2sql 样例文件等。 | **显式点出** `PROJECT_CONFIG`「未发现 workflows」与仓库 **`.github/workflows` 存在** 的潜在矛盾（低置信）；**显式点出** `13_flow` 图中 RPC **缩写**与 SQL 全名差异。 |
| **风险** | 声明 **未读** `docs/_tech_graph/*.md`（符合 Prompt）；全文自报「通读」体量极大，若与单次会话实际不符需人工抽检。 | 依赖「subagent 核验」表述，读者需信任核验过程；对图谱 **全文阅读**有勾选表，透明度好。 |

**简述**：两轮补丁后 **A 的代码层可靠性很强**；**B** 在 **文档真值 vs 仓库现状** 的 **显性矛盾提示** 上更占优，更符合「少幻觉、少漂移」的 P2 定义。

## 3. 综合结论（服从 P1>P2>P3>P4）

- **补丁的核心效果**：**A 组**已把 **manifest / contract / manifest_check / contract_check** 写进接手清单与配方卡，**与 B 组在「门禁必做」上收敛**；差异转向 **信息量形态**（A 偏实现讲义，B 偏索引 + 元层防漂移）。
- **按你的 KPI**：若必须在两者里选单一「总赢家」——**P2 略偏 B**（CONFIG/图谱缩写矛盾显式化），**P3 偏 B**，**P4 偏 A**；**P1 依角色分裂**（纯写码接手略偏 **A**，管图谱与 SSE 契约略偏 **B**）。
- **实操建议**：日常可 **以 B 补丁为导航与漂移提示，以 A 补丁为深读与改码手册**；二者合并心智模型最优，而非二选一。

---

## 4. 对外可复用的「补丁实验」结论一句话

**在「禁用图谱正文、仅放行 JSON 真值」的 A 补丁下，门禁与 CI 叙事已接近 B；B 仍以较低 token 与更强的元文档矛盾提示取胜，A 仍以更细的行级锚点与更短自报用时取胜。**
