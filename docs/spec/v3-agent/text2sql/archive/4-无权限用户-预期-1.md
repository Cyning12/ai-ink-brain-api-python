## 实现说明（2026-05-12）

**现象**：仅看到 `tool.call.end` 的 `error`，没有 `agent.llm.*` 与前端意义上的「answer」流。

**原因**：`_emit_post_tool_chains` 原先用 `tr.success and answer_text` 才调用 `_emit_simulated_llm`；无权限时 `success=false`，模拟总结不发射。

**修复**：当 `next_action=final_answer` 且 `answer_text_for_llm` 非空时，**即使** `tr.success` 为 false，仍发射 `text2sql_summary` 模拟流；`agent.final` / `assistant.message` 的 `content` 与该正文一致。上方 JSON 若缺 `agent.llm.*` 帧，请用新版本再导出 Timeline。
