## 改进需求（INSERT 列名臆测）

上文 `tool.call.end` 中 Postgres 报错：`column "id" of relation "agent_info" does not exist`，说明在 **检索到的 DDL 不足以约束列名** 时，模型仍生成了带臆测列的 `INSERT`。

**需求**：当判定 **缺少目标表的有效结构（列名/类型）** 且意图为 **写入/更新** 时，应 **先只读拉取表结构**（如 `information_schema` 等），再进入 SQL 生成，避免无锚点猜列。

**任务单**（实现与验收）：[`docs/tasks/active/task_text2sql_schema_prefetch_before_mutate_v1.md`](../../../tasks/active/task_text2sql_schema_prefetch_before_mutate_v1.md)
